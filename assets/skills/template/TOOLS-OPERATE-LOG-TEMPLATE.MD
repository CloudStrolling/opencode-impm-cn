# 操作审计日志埋点检查报告
**项目名称**：**检查日期**：**检查人**：TL **标准依据**：GB/T 22239-2019《信息安全技术 网络安全等级保护基本要求》第三级安全要求 — 安全审计（8.1.4.3）

## 使用说明
1. 本报告针对等保三级"安全审计"控制点中要求的关键操作审计日志埋点进行逐项检查。
2. 检查范围覆盖六大类关键操作场景：用户认证、权限变更、数据导出、敏感配置变更、业务关键操作、异常与安全事件。
3. 每个检查项的检查结果只能取三种取值：
   - 通过：有代码、配置或文档证据表明该操作场景已实现审计日志记录，且日志字段完整、防护措施到位；
   - 不通过：未找到审计日志埋点证据，或日志字段不完整、防护措施缺失，必须在说明中写明具体不通过原因；
   - 不适用：当前项目确实不存在该操作场景，必须在说明中写明理由。
4. 检查证据需给出文件路径（含行号）、日志框架配置位置或代码实现位置。
