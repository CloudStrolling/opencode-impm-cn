# impm-coding-review 技能

## 触发词
代码审核、代码评审、code review、审核报告、安全审查

## 何时使用
阶段4中，代码备注完成后，需要对本次版本代码进行全面审核并输出审核报告时使用。

## 执行角色
本技能由 技术负责人（subagent_type=tl）subagent 负责执行，执行时使用 Skill 工具加载本技能。

## 调度说明（PM/上级编排者启动本技能时必须遵守）
1. 启动方式：使用 task 工具启动 subagent，subagent_type 必须为 `tl`；禁止由 PM 或编排者自己代替执行本技能内容。
2. 提示词必传上下文（缺一不可）：项目根目录绝对路径（projectRoot）、项目英文缩写（{项目英文缩写}）、当前版本号（{当前版本号}）、用户输入 $ARGUMENTS 原文（含用户提到的文件路径）、技能名（impm-coding-review，要求 subagent 先用 Skill 工具加载本技能再执行）。
3. 完成要求：等待 subagent 返回完成结果后，核对产出文件与 version_progress.md 进度记录，全部正确后才能进入下一步。

## 关键变量定义与取值
| 变量 | 说明 | 获取方式 |
| 项目中文名称 | 项目的中文名称 | 通过 impm_project_info 从 docs/project.md 读取 |
| 项目英文名称 | 项目的英文名称 | 通过 impm_project_info 从 docs/project.md 读取 |
| 项目英文缩写 | 项目的英文缩写，用于拼接所有文档路径 | 通过 impm_project_info 从 docs/project.md 读取 |
| 当前版本号 | 当前执行的版本号 | 通过 impm_version action=current 获取，或从版本目录名推断 |

## 执行要求
1. 严格按照执行步骤中的内容和顺序依次执行：不跳过、不乱序、不并行、不合并任何步骤。
2. 只执行本技能规定的操作，不做与任务无关的工作。本技能只审核、不修复：不修改任何文件。
3. 所有文档路径必须用 {项目英文缩写} 和 {当前版本号} 拼接，不得臆造文件名。
4. 使用 impm_* 工具获取信息，不得编造工具返回结果。
5. 全程使用简体中文。
6. 每个步骤完成后，核对产出文件是否存在、内容是否正确。

## 执行步骤
### 步骤 1：确定审核范围
1. 调用 impm_git（action=log、action=status）确定本次版本更新的代码文件清单。
2. 结合 docs/{项目英文缩写}-v{当前版本号}/ 下的 URS、PRD、LLD 与测试用例文档，明确审核范围与重点。

### 步骤 2：发现安全漏洞
1. 检查是否存在注入风险（SQL 注入、命令注入、XSS 等）。
2. 检查是否存在越权访问（未校验权限、水平/垂直越权）。
3. 检查是否存在硬编码密钥、口令、Token。
4. 检查是否存在敏感信息泄露（日志、错误信息、响应体中泄露敏感数据）。

### 步骤 3：识别性能陷阱
1. 检查是否存在 N+1 查询、循环内查询数据库。
2. 检查是否存在内存泄漏隐患（未释放资源、未关闭连接、全局缓存无限增长）。
3. 检查是否存在不必要的循环与重复计算。
4. 检查是否存在大数据量全表扫描、缺失索引的大表查询。

### 步骤 4：检查代码质量
1. 检查重复代码、过长函数、过长文件。
2. 检查命名是否清晰、可读性是否达标。
3. 检查注释是否充分、与代码是否一致。

### 步骤 5：验证架构合规性
1. 检查分层是否清晰，是否符合 docs/{项目英文缩写}-sad.md 与 LLD 中的架构设计。
2. 检查是否违反依赖方向（如底层依赖上层、跨层直接访问）。
3. 检查是否绕过已定义的接口直接操作内部实现。

### 步骤 6：确认测试覆盖
1. 检查关键路径是否有对应的测试用例与测试代码。
2. 检查边界条件、异常路径是否覆盖。
3. 对测试缺口给出明确提示。

### 步骤 7：读取代码审核报告模板
1. 调用 impm_template_reader 读取 REVIEW-TEMPLATE.MD 模板内容。

### 步骤 8：按模板格式写入审核报告
1. 将步骤 2 至 6 的发现整理为审核报告，严格按模板格式填写：审核范围、问题清单（严重级别、所在文件与位置、问题描述、修改建议）、测试覆盖评估、总体结论。
2. 只输出审核意见，不修改任何文件。
3. 调用 impm_doc_writer（docType=review）写入 docs/{项目英文缩写}-v{当前版本号}/{项目英文缩写}-review.md。
4. 核对文件存在且内容正确。

### 步骤 9：记录进度
1. 调用 impm_progress add（impm-coding-review，已完成），在 version_progress.md 中记录本技能完成状态。
2. 核对 version_progress.md 中已记录本步骤状态。

## 交付物
- docs/{项目英文缩写}-v{当前版本号}/{项目英文缩写}-review.md（审核报告）
- version_progress.md 进度记录

## 完成后提示
- 本技能全部操作完成后必须立即结束并返回调度方（产出清单与 version_progress.md 进度状态）；严禁自行继续执行后续技能，后续步骤请由调度方（PM）输入 /impm-project-update、/impm-finish 继续。
